شام ستايل — ملفات الموقع

الملفات:
- index.html: واجهة الزبائن والسلة والطلب عبر واتساب.
- admin.html: لوحة إضافة وتعديل وحذف المنتجات.
- products.json: بيانات المنتجات التي يقرأها المتجر.

النشر الأول:
1) ارفعي الملفات الثلاثة إلى جذر مستودع GitHub sham-style-store.
2) اعملي Commit changes.
3) فعّلي GitHub Pages من Settings > Pages > Deploy from a branch > main > /(root) إذا لم يكن مفعلاً.

الروابط بعد النشر:
المتجر: https://sham-style.github.io/sham-style-store/
الإدارة: https://sham-style.github.io/sham-style-store/admin.html

تحديث المنتجات لاحقاً:
1) افتحي لوحة الإدارة من نفس المتصفح والجهاز.
2) أضيفي/عدّلي/احذفي المنتجات.
3) اضغطي «تنزيل ملف المنتجات للتحديث على الموقع».
4) ارفعي products.json الجديد إلى GitHub مكان الملف القديم واعملي Commit.

ملاحظات مهمة:
- هذه النسخة لا تستخدم Supabase ولا Google Sheets.
- لا يوجد تزامن تلقائي: لوحة الإدارة تحفظ محلياً، ويجب رفع products.json بعد التعديل حتى يظهر للزبائن.
- صور الملفات تُضغط وتُضمّن داخل products.json. كثرة الصور الكبيرة قد تجعل الملف كبيراً.
- الطلب يفتح واتساب برسالة جاهزة؛ الزبونة تضغط إرسال داخل واتساب.
- رقم واتساب المستخدم: 963997050453.
- لوحة الإدارة ليست محمية بكلمة مرور. لا تنشري رابطها علناً؛ لكنها ليست نظام دخول آمناً.
